The end state, in one line.

An objective and its key results: where to go, and how to tell you are getting there ([re:Work](https://rework.withgoogle.com/intl/en/guides/set-goals-with-okrs)). Fill it in over this guide.

- objective: an end state, obvious to an outsider whether it was met. "ship feature Y", not "keep doing X"
- key results: about 3, each measurable, each an outcome, not an activity
- one active at a time
- status: draft, active, archived, dropped
- issues hang under it by `belongsTo`
- not a to-do list
